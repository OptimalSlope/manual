## Save and Run the Simulation 1. Choose **File > Save As** and save the project as `{{ page.project_file }}` in the exercise folder. Use a separate working folder if you want to keep the supplied reference project for comparison. 2. Open the **Simulation** tab and select `{{ page.section_name }}`. 3. Set **Simulation results location** to **Automatic**. A section simulation folder is created beside the saved `.cbf` project when the simulation starts. 4. Click **Start**. If **Simulation Check** lists an issue, use **Fix** to open the affected field, correct it, and select **Check Again**. 5. Once the check passes, click **Start** again. Review any later geometry or groundwater warnings and enter your configured username when requested. 6. Monitor the **Node status** summary and use **Fetch results** to retrieve the output. For more detail, see [Running Simulations]({{ '/pages/Tutorials/Workflow/#running-simulations' | relative_url }}). If the analysis does not start, use [Simulation Does Not Start]({{ '/pages/troubleshooting/#simulation-start' | relative_url }}).
